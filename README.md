# AutoReply

Автоответчик для Android. Читает уведомления мессенджеров и отвечает на личные сообщения заданным текстом через кнопку «Ответить» в самом уведомлении.

Без регистрации, без смс, без рекламы. У приложения нет доступа в интернет, ничего никуда не отправляется.

## Возможности

- Поддерживаются Telegram, WhatsApp, Instagram, Viber, VK, MAX. Приложение работает там, где в уведомлении есть кнопка «Ответить».
- Для каждого мессенджера свой переключатель.
- 4 готовых шаблона ответа. Нажми, чтобы применить, удержи, чтобы сохранить в шаблон свой текст.
- Один человек получает автоответ не чаще, чем раз в N минут (настраивается).
- Группы и сводные уведомления пропускаются.
- Плитка в шторке и виджет на рабочем столе: включение одним касанием.
- Связка с режимом «Не беспокоить»: включился режим, включился AutoReply, и наоборот. Отключается в настройках.
- Постоянное уведомление «AutoReply активен · Отвечено: N раз».
- Журнал последних 50 ответов, хранится только на телефоне.

## Установка

1. Скачай `AutoReply-release.apk` из раздела [Releases](../../releases/tag/latest).
2. Установи и открой приложение.
3. Нажми «Доступ к уведомлениям» и включи доступ для AutoReply.
4. Включи автоответчик переключателем.

Плитка: потяни шторку, нажми карандаш и перетащи AutoReply. Виджет: долгое нажатие на рабочий стол, Виджеты, AutoReply.

Требуется Android 7.0 и новее.

## Сборка

Проект собирается через GitHub Actions: любой push в `main` собирает подписанный APK и обновляет релиз `latest`. Нужны Java 17 и Gradle 8.11.

## Частые вопросы

**Зачем нужен доступ к уведомлениям?**
Так AutoReply узнаёт о новом сообщении и отвечает через кнопку «Ответить» в уведомлении. Без этого доступа приложение работать не может. Интернет ему не нужен: такого разрешения у приложения нет, поэтому отправить что-то наружу оно не может.

**Приложение читает мои сообщения?**
Оно видит заголовок и текст уведомления, но только чтобы решить, отвечать или нет. Ничего не сохраняется и не передаётся. В журнал попадают только время, мессенджер и имя собеседника, текст сообщений туда не записывается.

**Кому и как часто оно отвечает?**
Только на личные сообщения. Группы и сводные уведомления пропускаются. Один и тот же человек получает автоответ не чаще, чем раз в N минут. По умолчанию это 60 минут, изменить можно в приложении.

**Почему оно не отвечает?**
Проверь по порядку:
1. Доступ к уведомлениям включён для AutoReply.
2. Автоответчик включён, а переключатель нужного мессенджера в приложении стоит в положении «вкл».
3. В уведомлении есть кнопка «Ответить». Если её нет, ответить нельзя.
4. Чат не отключён: у отключённых чатов уведомлений нет.
5. Этому человеку уже отвечали меньше N минут назад.
6. Сообщение пришло в группу.

**Приложение перестало работать через некоторое время.**
Скорее всего, телефон выгрузил его ради экономии заряда. Открой настройки Android → Приложения → AutoReply → Батарея и выбери «Без ограничений».

**AutoReply включился сам. Почему?**
Включена связка с режимом «Не беспокоить»: включил режим, включился автоответчик, и наоборот. Отключить связку можно в настройках приложения.

**Отвечает ли оно на сообщения, пришедшие до включения?**
Нет, только на новые, пришедшие после включения.

**Как сменить текст ответа?**
Впиши свой текст на главном экране или нажми на один из 4 шаблонов. Чтобы сохранить свой текст в шаблон, удержи его.

**Как включить плитку и виджет?**
Плитка: потяни шторку, нажми карандаш и перетащи AutoReply. Виджет: долгое нажатие на рабочий стол → Виджеты → AutoReply.

**Что значит «Отвечено: N раз» в уведомлении?**
Столько автоответов отправлено с последнего включения. При каждом новом включении счётчик обнуляется.

**Какие мессенджеры поддерживаются?**
Telegram, WhatsApp, Instagram, Viber, VK и MAX. Другие мессенджеры не поддерживаются.
