# AutoReply

Автоответчик для Android. Читает уведомления мессенджеров и отвечает на личные сообщения заданным текстом через кнопку «Ответить» в самом уведомлении.

Без регистрации, без смс, без рекламы. У приложения нет доступа в интернет, ничего никуда не отправляется.

## Возможности

- Поддерживаются Telegram, WhatsApp, Instagram, Viber, VK, MAX. Приложение работает там, где в уведомлении есть кнопка «Ответить».
- Для каждого мессенджера свой переключатель.
- 4 готовых шаблона ответа. Нажми, чтобы применить, удержи, чтобы сохранить в шаблон свой текст.
- Один человек получает автоответ не чаще, чем раз в N минут (настраивается).
- Группы и сводные уведомления пропускаются.
- Плитка в шторке и виджет на рабочем столе: включение одним касанием.
- Связка с режимом «Не беспокоить»: включился режим, включился AutoReply, и наоборот. Отключается в настройках.
- Постоянное уведомление «AutoReply активен · Отвечено: N раз».
- Журнал последних 50 ответов, хранится только на телефоне.

## Установка

1. Скачай `AutoReply-release.apk` из раздела [Releases](../../releases/tag/latest).
2. Установи и открой приложение.
3. Нажми «Доступ к уведомлениям» и включи доступ для AutoReply.
4. Включи автоответчик переключателем.

Плитка: потяни шторку, нажми карандаш и перетащи AutoReply. Виджет: долгое нажатие на рабочий стол, Виджеты, AutoReply.

Требуется Android 7.0 и новее.

## Сборка

Проект собирается через GitHub Actions: любой push в `main` собирает подписанный APK и обновляет релиз `latest`. Нужны Java 17 и Gradle 8.11.
